## Файлы

- **preview.html** — автономный визуальный образец: инвентарь, примерка, крафт, пустое состояние, форма добавления. Открой файл в браузере; меню справа внизу переключает примеры. Интернет, сборка, авторизация и сервер не требуются.
- **sites.css** — фактический CSS из одобренного Site; удалена только строка импорта Tailwind, чтобы образец открывался автономно. Это справочник оформления, а не готовая замена CSS основного приложения с другими классами.
- **tokens.json** — палитра, размеры, брейкпоинты и контрольные хеши исходного/автономного CSS.
- Авторитетное задание на внедрение — **.delivery/tasks/TASK-004.md**.

В HTML зафиксированы вымышленные демонстрационные значения. У кнопок нет игровой логики: переключаются только визуальные примеры и открывается форма. Это **эталон дизайна**, не новая функциональная реализация калькулятора. Кнопки статичного примера не являются основанием менять реальное поведение.

## Что должно быть узнаваемо

- Тёмная графитово-зелёная поверхность, более светлые карточки, тонкие спокойные границы.
- Лаймовый главный акцент #c5f469, тёплый светлый текст; цветные пиктограммы четырёх модов.
- Боковая навигация на широком экране, основной список модов слева, параметры персонажа и расход справа.
- Отчётливые числа урона/здоровья, уровень и счётчик 100 слотов; компактные карточки групп с параметром, уровнем и количеством.
- Мастерская с тремя входными слотами, стрелкой, результатом и ценой; кнопки отмены/сброса второстепенные.
- Визуально связанные табы, фильтры, редактор, пустые состояния и сообщения сохранения/ошибок.
- На телефоне — одна колонка с удобным доступом к параметрам; без горизонтальной прокрутки страницы. Мелкие подписи эталона адаптировать до читаемого размера, интерактивные цели основного приложения сохранять не менее44px.

## Как сопоставлять с основным приложением

| В эталоне | Источник поведения в основном приложении |
| --- | --- |
| Инвентарь | scope original, pages.original, обработчики original.put/original.delete |
| Примерка | scope work, state.equipment/equippedMods, массовый equip, лимит100 |
| Крафт | тот же work; selection с id/quantity/worn, preview из @chm/rules и существующий craft |
| Уровень, урон, HP, расход | текущий summary сервера; редактирование уровня через существующую команду |
| Сохранение/ошибка | существующие message/problem/busy/pending/conflict, а не декоративный текст |
| Форма | действующие валидаторы/числовые строки и обработчики формы |
| Сброс и отмена | текущие reset/undo и подтверждение последствий |
| Нужные дополнительные элементы | вкрафт с персонажа, массовое количество, все надетые, pagination, retry/refresh/logout/login сохраняются и получают ту же стилистику |

## Что переносить нельзя

В основной продукт не переносятся ChatGPT Sign-in, D1, Cloudflare/Vinext, Sites endpoints, команда demo, отдельная модель данных/арифметика Sites, собственные правила выбора ненадетых экземпляров или примеры чисел. Основной продукт сохраняет Telegram OIDC/Mini App, Fastify/React/Vite/SQLite и свой API.

Работающие возможности, которых нет в упрощённом образце, получают оформление в той же системе. Их нельзя убирать, менять правилами Sites или прятать до недоступности. В частности, сохраняется явный выбор **надетых** экземпляров для крафта и точное поле количества при примерке.

Если глобальные количества API не предоставляет, не выдавать число загруженных страниц за размер всего инвентаря. Использовать существующие достоверные показатели либо подпись «Загружено групп» без нового API ради декоративного бейджа.
