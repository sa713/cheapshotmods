# Подключение инструментов

Проверено по официальной документации 2026-11-05; ссылки — [SOURCES](../SOURCES.md) в исходном репозитории. Доступность функций зависит от аккаунта и среды. Возможность необходимо проверить фактическим чтением/запуском; не выводить её из названия подписки.

## Общие условия

- Для каждого инструмента подтвердить доступ к приватному продуктовому репозиторию и нужной ветке, правилам и задаче. Наличие ссылки не выдаёт доступ.
- Чтение, запись, команды, браузер, preview, PR и выпуск — отдельные возможности. Записать доступные/недоступные в паспорт.
- Секреты передавать штатным механизмом среды; не вставлять их в README, задачи или ответы.
- Подписки не являются безлимитным API-бюджетом. Work и Codex могут расходовать общий лимит OpenAI; Claude и Claude Code — общий лимит Claude. Выбор API/дополнительных кредитов требует соответствующего разрешения.
- Нет прямого запуска другого сервиса — выдать готовое поручение, не строить фиктивную фоновую координацию. При исчерпании лимита сохранить состояние, указать следующий шаг и не заявлять о продолжении вне активной задачи.

## ChatGPT / Work

Один ChatGPT-проект организует два чата. В инструкциях проекта указать ссылку на продукт, точку входа `.ai-development/START.md` и необходимость восстанавливать состояние из репозитория. Роль задаётся стартовым сообщением чата.

В обычном Chat чтение/запись GitHub могут отсутствовать. Для репозиторных действий использовать Work с подключённым GitHub или передать законченный пакет в управляющий чат. Не предполагать автоматического чтения AGENTS.md только потому, что его ссылка добавлена к проекту. Первое сообщение явно требует чтения.

Личные навыки устанавливаются штатным механизмом ChatGPT; они не являются единственным хранилищем правил. Вызов по имени зависит от интерфейса; при отсутствии навыка использовать сообщения из README. После установки проверить его видимость в новой сессии и чтение целевого стандарта. Механика личной установки не изменяет автоматически копии в продуктовых репозиториях.

## Codex Cloud

Подключить продуктовый репозиторий, подготовить окружение с реальными зависимостями и командами проверки. Сохранить проверенный setup. Каждая задача получает правильную ветку/базу. AGENTS.md задаёт постоянные инструкции; `.agents/skills/` содержит репозиторные навыки, если поддерживается выбранной средой.

Скрипт подключения добавляет три навыка в `.agents/skills/`. Проверить их обнаружение и фактическое чтение локальной версии стандарта. Личные навыки другого окружения не считать автоматически синхронизированными.

Не считать встроенное управление браузером или внешний preview доступными по умолчанию. Если нужны UI-проверки, подтвердить доступный браузерный инструмент либо настроенный запуск браузерных тестов/скриншотов, а пользовательскую демонстрацию сделать доступной владельцу. Отсутствие GUI не отменяет возможность статического/серверного анализа, но ограничение записывается.

Встроенный GitHub code review может служить дополнительной проверкой diff. Он не заменяет проверку всей спецификации или работающего продукта. Автоматическое ревью включать только после проверки доступа и настроек; файл Markdown этого не включает.

## Claude в обычном чате — текущий маршрут

Владелец вручную передаёт готовое поручение и материалы с телефона. Management готовит пакет по [REVIEW_CHAT](REVIEW_CHAT.md), принимает ответ текстом/файлом и сохраняет его. Чтение приватного GitHub, выполнение команд и установка навыков в этом чате не предполагаются. Ссылка без подтверждённого доступа заменяется читаемым пакетом; ссылка на закрытый чат не заменяет его содержимое.

Claude анализирует доступные требования, решения и исходный код. Фактическое исполнение проверок обеспечивается Codex/Work/CI; независимый запуск, когда он требуется, выполняется отдельной сессией с нужными возможностями. Отчёт всегда указывает область и реальные ограничения. Ноутбук владельца для этой схемы не требуется.

Автоматический запуск Claude, GitHub Action и настройка его токена отложены по выбору владельца. Общая цель сократить передачи не отменяет этого решения. Будущее подключение автоматизации требует отдельного изменения выбранного маршрута.

## Claude Code — дополнительный вариант

Подключить GitHub и среду выполнения команд. CLAUDE.md импортирует AGENTS.md; существующие инструкции сохраняются. Скрипт подключения также размещает репозиторные навыки в `.claude/skills/`.

Способ загрузки навыков зависит от поверхности: локальные сессии и некоторые облачные сессии могут использовать репозиторные навыки, тогда как облачные потоки внутри Claude Projects могут требовать навыка аккаунта. Личные навыки с локального компьютера не считать доступными в облаке автоматически. В каждом используемом режиме проверить обнаружение; если оно не поддержано, дать явную команду прочитать правила и роль по README. Формат SKILL.md содержит только переносимые name/description; расширения конкретного клиента не нужны для выполнения процедуры.

Для ревью используется новая сессия с исходным требованием/PR. Отсутствие инструмента записи отчёта не мешает выдать отчёт текстом, но факт сохранения не выдумывать. Отсутствие команды запуска тестов не выдавать за выполненные тесты.

## Контроль подключения

Управляющий записывает, что фактически проверено: прочитан заданный файл/HEAD, найдено задание, запущена указанная безопасная команда, доступен preview или описана альтернатива. Если подтверждена только документация, так и написать. Проверка нового режима не требует изменений production или платных вызовов.
