# Cheapshot Mods · «Верстак» (редизайн v2)

Независимая интерпретация интерфейса. Бизнес-логика, API, сервер, схема БД и правила расчётов не менялись: изменены только `apps/web/src` и браузерные тесты.

## Что мешало в прежнем интерфейсе

1. **Три пересекающиеся навигации.** Боковое меню («Мой инвентарь / Примерка / Крафт модов»), вкладки над списком («Исходный набор / Эксперимент / Крафт») и названия не совпадали. «Примерка» и «Крафт» открывали один и тот же экран, «Крафт» только прокручивал к панели.
2. **Крафт оторван от выбора.** Моды выбирались кнопками в списке, а слоты и результат — далеко внизу (на телефоне ~4 экрана ниже). Убрать один выбранный мод было нельзя, только «Очистить выбор».
3. **Шум в каждой строке.** 2–3 равнозначные кнопки на строке («Примерить / снять», «В крафт», «В крафт с персонажа») плюс подписи «В наборе: · Надето:». На телефоне строка мода занимала до 150 px.
4. **Неразличимые фильтры.** Пять из семи фильтров подписаны «Урон».
5. **Длинная мобильная страница.** Персонаж, список, крафт, массовый фьюз, зелёные рецепты, точка возврата и сбросы — одна лента ~5 400 px. Нужные действия приходилось искать прокруткой.
6. **Массовый фьюз — форма-простыня.** Повторы значений («Разрешено: N», «Выбрано результатов: —»), выпадающий список для 2–5 вариантов уровня, зелёные рецепты вложены в массовый фьюз.
7. **Слабая обратная связь.** Успех — только мелкий текст в шапке; ошибка появляется вверху страницы, далеко от действия на телефоне. Нет быстрой отмены сразу после крафта.
8. **Маркетинговые тексты вместо полезного места** («ПЛАНИРУЙ. ПРИМЕРЯЙ. УСИЛИВАЙ.», «НОВАЯ СИСТЕМА МОДОВ»), системный `confirm()` при удалении.

Что было удачно и сохранено: точные большие числа без потерь, расчёт до применения, идемпотентный повтор команды, понятные тексты ошибок, доступные модальные окна, цели нажатия ≥ 44 px.

## Концепция

Спокойный инструмент для регулярной работы: нейтральные поверхности, один акцентный цвет, цифры крупно, всё остальное — вторично. Светлая и тёмная тема (системная настройка или `Telegram.WebApp.colorScheme`). Только системные шрифты — CSP приложения запрещает внешние.

**Информационная архитектура — три раздела по задачам пользователя:**

| Раздел | Задача | Что внутри |
| --- | --- | --- |
| Эксперимент | «Что у меня сейчас и что будет, если…» | Рабочая копия модов, фильтры с количеством, лоток крафта |
| Крафт | «Сколько стоит и что получится» | Переключатель «Три в один / Массовый фьюз / Зелёные рецепты» |
| Исходный набор | «Что есть в игре» | Список с правкой, точка возврата (фиксация и возврат) |
| Персонаж | «Мои характеристики» | Уровень, урон, здоровье, крит, экипировка, расход, отмена, сброс |

На компьютере «Персонаж» — постоянная правая колонка, разделы — в левой. На телефоне — нижняя панель из четырёх вкладок и сводная строка характеристик над списком.

## Ключевые решения

- **Строка мода = одно основное действие.** Кнопка «+» добавляет свободный экземпляр в крафт. Нажатие на строку открывает карточку мода (нижний лист на телефоне): примерка со степпером, «В крафт» / «В крафт с персонажа», «Массовый фьюз этой группы», «Уточнить крит».
- **Лоток крафта.** При выборе первого мода снизу появляется компактный лоток: три слота, результат, цена, «Применить крафт». Слот снимается нажатием. Когда выбраны три входа, кнопки «+» блокируются вместо ошибки.
- **Крафт без перехода.** В разделе «Крафт» → «Три в один» есть список совместимых модов, поэтому крафт можно собрать прямо там.
- **Массовый фьюз:** целевой уровень — сегменты вместо выпадающего списка, кнопка «Макс», результат одной строкой («2 × 🅾️ 3.0 · +23%»), переходы свёрнуты, полная цена выделена. Зелёные рецепты — отдельная вкладка, расход сырья таблицей.
- **Редактор группы:** тип, уровень и параметр — сегменты на нативных radio (клавиатура из коробки), для 💢/🧿 1.0 и сырья фиксированные значения показаны текстом, а не заблокированным полем. Удаление — внутри редактора с подтверждением в окне приложения.
- **Обратная связь:** статус сохранения с цветовой точкой и кнопкой обновления в шапке; баннер с действиями «Повторить ту же команду» / «Загрузить актуальные данные» сразу под шапкой; короткое уведомление об успехе, после крафта и фьюза — с кнопкой «Отменить».
- **Большие числа:** все значения `.exact` переносятся без обрезки; в компактном лотке очень длинные значения сокращаются визуально (`+999…99%`), полное значение остаётся в доступном тексте, в разделе «Крафт» и в подсказке.
- Состояние форм массового фьюза и рецептов сохраняется при переключении разделов.

## Идеи за рамками редизайна (не реализованы)

- Поиск по значению/уровню и сортировка по количеству в списке.
- Фильтр «только надетые» и «только с неизвестным критом».
- Сравнение «до/после» характеристик в карточке мода перед применением примерки.
- История операций с выборочным просмотром (сейчас отмена только последней — так в правилах).
- Использование `themeParams` Telegram для точного совпадения цветов Mini App.
- Хаптика Telegram (`HapticFeedback`) на успех/ошибку команды.
