# Cheapshot Mods

Калькулятор модов Cheapshot: исходный инвентарь, один сохраняемый эксперимент, крафт и его стоимость, примерка на персонажа. Планируются сайт для телефона и Telegram Mini App с общими данными игрока.

- [Согласованные требования](PRODUCT.md) — полный продуктовый объём; документ сохранён без изменений.
- [Паспорт и полномочия](.delivery/PROJECT.md).
- [Текущий шаг](.delivery/STATE.md) и [очередь](.delivery/TASKS.md).
- [Готовое задание TASK-001](.delivery/tasks/TASK-001.md) — первая техническая реализация.
- [Техническая проработка](.delivery/TECHNICAL.md) и [эксплуатация](.delivery/RUNBOOK.md).
- Вход для агента: [AGENTS.md](AGENTS.md), затем [.ai-development/START.md](.ai-development/START.md).

Реализуется техническая основа TASK-001: точная игровая модель, сохраняемый эксперимент, API и два адаптера Telegram на фикстурах. Полный мобильный интерфейс, живой вход и внешнее размещение ещё не приняты. Фактические результаты и ограничения — в карточке, команды — в RUNBOOK.
