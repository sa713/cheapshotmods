# Cheapshot Mods

Калькулятор модов Cheapshot для мобильного браузера и Telegram Mini App. Оба способа входа открывают один сохранённый инвентарь и эксперимент игрока.

Приложение позволяет вводить обычные и сырьевые моды, примерять до 100 экземпляров, рассчитывать урон/здоровье/крит, выполнять одиночный и массовый многоступенчатый фьюз, видеть расход алмазов, отменять действия и сбрасывать эксперимент. В массовом фьюзе выбираются одна группа одинаковых модов и целевой уровень; доступный максимум вычисляется автоматически. TASK-009 добавляет фиксированные зелёные рецепты6+6+7→🅾1.0/10 и7+8+8→🅾1.0/12, цену28за результат и единый порядок модов до разбиения на страницы. Выпадающие списки оформлены в теме приложения, включая варианты внутри диалогов.

Кнопка «Зафиксировать исходный набор модов» сохраняет введённый инвентарь как постоянную точку возврата. «Сбросить набор модов к исходному» возвращает инвентарь и эксперимент к этому снимку, очищает фьюзы, расход и экипировку. Прежняя кнопка «Сбросить эксперимент» возвращает рабочие моды к текущему введённому набору. Уровень игрока сохраняется при обоих сбросах.

Актуальный интегрированный код находится в **main**. Код, тесты, инструкции запуска и история изменений входят в репозиторий.

## Локальный запуск

Требуются Node.js **24.22.1** и npm **11.9.0** — версии закреплены в .nvmrc/package.json.

```bash
git clone https://github.com/sa713/cheapshotmods.git
cd cheapshotmods
bash scripts/verify.sh
cp .env.example .env
```

Для личной работы настройте в .env постоянный SESSION_SECRET длиной не менее 32 символов и Telegram-вход согласно [инструкции](deploy/README.md). Параметры OIDC задаются парой client ID/client secret; Mini App использует токен бота. Значения секретов остаются локальными.

```bash
npm start
```

Локальный адрес по шаблону конфигурации — http://localhost:3000. Без настройки Telegram-входа сервер запускается с экраном входа, личный инвентарь недоступен. Для разработки с пересборкой клиента и сервера есть `npm run dev` (клиент на 5173); для реального Telegram нужны соответствующие разрешённые origin/callback.

## Проверки

`bash scripts/verify.sh` устанавливает зависимости по lock-файлу, выполняет typecheck, lint, native-тесты и build. Для браузерных сценариев:

```bash
npx playwright install --with-deps chromium
npm run test:browser
```

Тесты используют отдельные данные/подписанные тестовые Telegram-сценарии. Они не требуют рабочих секретов владельца и не заменяют наблюдение живого Telegram.

## Структура

- `apps/web` — React-интерфейс «Верстак»: разделы «Эксперимент», «Крафт», «Исходный набор» и панель «Персонаж»; концепция и экраны — [.delivery/design/workbench-v2](.delivery/design/workbench-v2/README.md).
- `apps/server` — Fastify, Telegram-вход, SQLite, команды и история.
- `packages/rules` — общие правила, точная арифметика и планировщик фьюза.
- `tests` — native/API/браузерные проверки.
- `deploy` и `scripts` — сборка, установка и проверки комплекта.
- `.delivery` — задачи, решения, эксплуатация и доказательства проверок.
