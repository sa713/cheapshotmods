# Паспорт продукта

Этот документ заполняет управляющий при подключении. Значение `не определено` обозначает реальный пробел, а не разрешение придумать факт. До реализации блокирующие поля должны быть заполнены.

## Продукт и источники

- Название: не определено
- Репозиторий и основная ветка: не определено
- Владелец: не определено
- Назначение и пользователи: не определено
- Требования/сценарии: `.delivery/PRODUCT.md` (либо указать существующий путь)
- Очередь задач: `.delivery/TASKS.md` (либо единый GitHub issue tracker)
- Состояние: `.delivery/STATE.md` — решения и следующий шаг; текущие HEAD/CI/слияние — GitHub
- Эксплуатация: `.delivery/RUNBOOK.md`
- Технические решения: раздел требований либо существующий документ; отдельные записи при необходимости
- Версия стандарта: `.ai-development/manifest.json`

## Техническая среда

- Тип продукта, стек, поддерживаемые платформы: не определено
- Установка зависимостей и запуск: не определено
- Проверки, обязательные CI jobs: не определено
- Тестовые данные/аккаунты и доступные интеграции: не определено
- Preview/демонстрация и устройство владельца: не определено
- Целевое окружение и способ доставки: не определено
- Ресурсные и внешние ограничения, бюджет: не определено
- Секреты: только названия переменных/способ предоставления, без значений

Среда готовится управляющим по guides/ENVIRONMENTS.md. В паспорте хранить ссылки на проверенные команды, CI и демонстрацию; техническую инструкцию не дублировать из RUNBOOK. Для каждого недоступного механизма указать действующий способ работы, а не оставлять будущую автоматизацию обязательной зависимостью.

## Полномочия

Зафиксировать основание (поручение/дата/ссылка), область и срок. Уже выданные разрешения действуют без повторного запроса.

| Действие | Действующее правило |
| --- | --- |
| Работа и PR | В пределах порученной задачи, отдельная ветка |
| Слияние | До явного решения владельца не разрешено |
| Публикация/production | До явного решения владельца не разрешено |
| Изменение рабочих данных | По конкретному плану и разрешению |
| Платные API/новые расходы | Без согласованного бюджета не разрешены |
| Внешние сообщения/рассылки | Только по явному поручению |
| Продуктовое принятие | Владелец; делегирование указать по классу задач |
| Параллельные реализации | По умолчанию одна; исключение с планом интеграции |

## Подключённые инструменты и отклонения

Для ChatGPT/Work, Codex и reviewer: доступ к чтению, записи, командам, preview, навыкам — подтверждено / недоступно / ещё не проверено, с датой и доказательством. Применимые отличия от общего стандарта описать явно с причиной и разрешением; не ослаблять критерии незаметно.

Текущий маршрут владельца: преимущественно телефон; ручная передача в обычный чат Claude. Management готовит сообщение/материалы и сохраняет возвращённый ответ. Claude Code и автоматический Claude-review не требуются. Отдельно указать исполнителя проверок с запуском кода и независимого воспроизведения по риску. Запуск Codex и фоновое продолжение управления отметить настроенными только после фактической проверки; иначе используется готовое ручное поручение/«Продолжай».
